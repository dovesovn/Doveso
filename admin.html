📋 Dán nhanh kết quả xổ số

Trang dành cho người quản lý. Sao chép bảng kết quả từ trang web uy tín, dán vào đây, kiểm tra lại, rồi tải file results.json lên GitHub. Trang này không thay đổi dữ liệu thật cho đến khi bạn tải file lên.

Đang tải results.json...

1. Dán bảng kết quả

Mỗi lần dán một bảng: một miền, đủ từ giải cao nhất đến giải thấp nhất (có thể nhiều đài cạnh nhau). Không cần dán phần thống kê lô tô.

2. Danh sách chờ lưu

Chưa có.

Sau khi tải: vào kho Doveso trên GitHub, Add file → Upload files, kéo file results.json vào, Commit changes. Mất 1–3 phút app sẽ cập nhật.
